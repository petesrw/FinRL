# 🧠 Reinforcement Learning และ PPO Algorithm

## 🎯 Reinforcement Learning คืออะไร?

**Reinforcement Learning (RL)** เป็นวิธีการเรียนรู้ของ AI ที่เลียนแบบการเรียนรู้ของมนุษย์

### **เปรียบเทียบง่ายๆ**

**เหมือนการสอนเด็กเล่นเกม**:
1. เด็กลองเล่น (Action)
2. ได้ผลลัพธ์ (Reward/Punishment)
3. เรียนรู้จากผลลัพธ์
4. ปรับปรุงวิธีเล่น
5. เล่นได้เก่งขึ้น

**ในการเทรด Forex**:
1. AI ลองซื้อ-ขาย (Action)
2. ได้กำไรหรือขาดทุน (Reward/Punishment)
3. เรียนรู้จากผลลัพธ์
4. ปรับปรุงกลยุทธ์
5. เทรดได้ดีขึ้น

---

## 🏗️ องค์ประกอบของ RL

### **1. Agent (ตัวแทน)**
- **คืออะไร**: AI ที่เรียนรู้และตัดสินใจ
- **ในการเทรด**: โมเดล AI ที่เทรด Forex
- **หน้าที่**: สังเกตสถานการณ์และตัดสินใจ

### **2. Environment (สภาพแวดล้อม)**
- **คืออะไร**: โลกที่ Agent อยู่และทำงาน
- **ในการเทรด**: ตลาด Forex ที่จำลองขึ้น
- **หน้าที่**: ให้ข้อมูลและตอบสนองต่อการกระทำ

### **3. State (สถานะ)**
- **คืออะไร**: สถานการณ์ปัจจุบันที่ Agent เห็น
- **ในการเทรด**: ราคา, ตัวชี้วัดทางเทคนิค, โพซิชั่น
- **ตัวอย่าง**: ราคา XAUUSD = 2000, RSI = 70, มีโพซิชั่น Long

### **4. Action (การกระทำ)**
- **คืออะไร**: สิ่งที่ Agent สามารถทำได้
- **ในการเทรด**: Hold, Buy, Sell
- **ตัวอย่าง**: ตัดสินใจซื้อ XAUUSD

### **5. Reward (รางวัล)**
- **คืออะไร**: คะแนนที่ Agent ได้รับจากการกระทำ
- **ในการเทรด**: กำไร/ขาดทุนจากการเทรด
- **ตัวอย่าง**: ได้กำไร 100$ = Reward +1

### **6. Policy (นโยบาย)**
- **คืออะไร**: กฎเกณฑ์ที่ Agent ใช้ตัดสินใจ
- **ในการเทรด**: กลยุทธ์การเทรดที่ AI เรียนรู้
- **ตัวอย่าง**: ถ้า RSI > 70 ให้ขาย

---

## 🔄 วงจรการเรียนรู้ของ RL

```
1. Agent สังเกต State (ดูสถานการณ์)
         ↓
2. Agent เลือก Action (ตัดสินใจ)
         ↓
3. Environment ตอบสนอง (ตลาดเปลี่ยนแปลง)
         ↓
4. Agent ได้รับ Reward (กำไร/ขาดทุน)
         ↓
5. Agent เรียนรู้และปรับ Policy (ปรับกลยุทธ์)
         ↓
6. กลับไปข้อ 1 (วนซ้ำ)
```

## 🎭 PPO Algorithm คืออะไร?

**PPO (Proximal Policy Optimization)** เป็นอัลกอริทึม RL ที่ได้รับความนิยม

### **ทำไมใช้ PPO?**

**ข้อดี**:
- ✅ เสถียร (ไม่ผันผวนมาก)
- ✅ เรียนรู้เร็ว
- ✅ ใช้งานง่าย
- ✅ เหมาะกับการเทรด

**เปรียบเทียบกับวิธีอื่น**:
- **A2C**: เร็วแต่ไม่เสถียร
- **SAC**: เสถียรแต่ช้า
- **PPO**: สมดุลระหว่างความเร็วและเสถียรภาพ

## 🔧 PPO Parameters อธิบายละเอียด

### **1. Learning Rate (อัตราการเรียนรู้)**
```python
learning_rate=0.0003
```

**คืออะไร**: ความเร็วในการปรับปรุง Policy

**เปรียบเทียบ**:
- **สูง (0.01)**: เรียนรู้เร็ว แต่อาจไม่เสถียร
- **กลาง (0.0003)**: สมดุล (แนะนำ)
- **ต่ำ (0.0001)**: เรียนรู้ช้า แต่เสถียร

**เลือกอย่างไร**:
- เริ่มต้น: 0.0003
- ถ้าผลลัพธ์ผันผวน: ลดลง
- ถ้าเรียนรู้ช้า: เพิ่มขึ้น

### **2. N_Steps (จำนวน Steps)**
```python
n_steps=2048
```

**คืออะไร**: จำนวนข้อมูลที่เก็บก่อนอัพเดท Policy

**เปรียบเทียบ**:
- **น้อย (512)**: อัพเดทบ่อย แต่ข้อมูลน้อย
- **กลาง (2048)**: สมดุล (แนะนำ)
- **มาก (4096)**: ข้อมูลเยอะ แต่อัพเดทช้า

**เลือกอย่างไร**:
- ข้อมูลน้อย: ใช้ค่าต่ำ
- ข้อมูลเยอะ: ใช้ค่าสูง
- ทั่วไป: 2048

### **3. Batch Size (ขนาดกลุ่มข้อมูล)**
```python
batch_size=64
```

**คืออะไร**: จำนวนข้อมูลที่ประมวลผลพร้อมกัน

**เปรียบเทียบ**:
- **เล็ก (32)**: ใช้ RAM น้อย แต่ช้า
- **กลาง (64)**: สมดุล (แนะนำ)
- **ใหญ่ (128)**: เร็ว แต่ใช้ RAM เยอะ

**เลือกอย่างไร**:
- RAM น้อย: 32-64
- RAM เยอะ: 128-256
- GPU แรง: 512+

### **4. N_Epochs (จำนวนรอบการเรียน)**
```python
n_epochs=10
```

**คืออะไร**: จำนวนครั้งที่เรียนรู้จากข้อมูลชุดเดียวกัน

**เปรียบเทียบ**:
- **น้อย (5)**: เรียนรู้เร็ว แต่อาจไม่ลึก
- **กลาง (10)**: สมดุล (แนะนำ)
- **มาก (20)**: เรียนรู้ลึก แต่ช้า

**เลือกอย่างไร**:
- ข้อมูลซับซ้อน: เพิ่มขึ้น
- ต้องการความเร็ว: ลดลง
- ทั่วไป: 10

### **5. Gamma (ค่าลดอนาคต)**
```python
gamma=0.99
```

**คืออะไร**: ความสำคัญของรางวัลในอนาคต

**เปรียบเทียบ**:
- **ต่ำ (0.9)**: สนใจแค่ปัจจุบัน
- **กลาง (0.99)**: สมดุล (แนะนำ)
- **สูง (0.999)**: สนใจอนาคตไกล

**ในการเทรด**:
- Day Trading: 0.9-0.95
- Swing Trading: 0.99
- Long-term: 0.999

### **6. GAE Lambda**
```python
gae_lambda=0.95
```

**คืออะไร**: ปรับสมดุลระหว่าง Bias และ Variance

**เปรียบเทียบ**:
- **ต่ำ (0.8)**: Bias สูง, Variance ต่ำ
- **กลาง (0.95)**: สมดุล (แนะนำ)
- **สูง (0.99)**: Bias ต่ำ, Variance สูง

**เลือกอย่างไร**:
- ข้อมูลมี Noise: ใช้ค่าต่ำ
- ข้อมูลสะอาด: ใช้ค่าสูง
- ทั่วไป: 0.95

### **7. Clip Range (ช่วงการตัด)**
```python
clip_range=0.2
```

**คืออะไร**: จำกัดการเปลี่ยนแปลง Policy ในแต่ละรอบ

**เปรียบเทียบ**:
- **เล็ก (0.1)**: เปลี่ยนแปลงน้อย (เสถียร)
- **กลาง (0.2)**: สมดุล (แนะนำ)
- **ใหญ่ (0.3)**: เปลี่ยนแปลงมาก (เสี่ยง)

**เลือกอย่างไร**:
- ต้องการเสถียรภาพ: 0.1
- ต้องการความเร็ว: 0.3
- ทั่วไป: 0.2

### **8. Entropy Coefficient**
```python
ent_coef=0.01
```

**คืออะไร**: ส่งเสริมการสำรวจ (Exploration)

**เปรียบเทียบ**:
- **ต่ำ (0.001)**: สำรวจน้อย (Exploitation)
- **กลาง (0.01)**: สมดุล (แนะนำ)
- **สูง (0.1)**: สำรวจมาก (Exploration)

**เลือกอย่างไร**:
- เริ่มต้น: ใช้ค่าสูง (0.1)
- ระหว่างเทรน: ลดลงเป็น 0.01
- ใกล้จบ: ใช้ค่าต่ำ (0.001)

## 🎯 เทคนิคการปรับแต่ง

### **1. เริ่มจากค่า Default**
```python
# ใช้ค่ามาตรฐานก่อน
learning_rate=0.0003
n_steps=2048
batch_size=64
```

### **2. ปรับทีละตัว**
```python
# ปรับ learning_rate ก่อน
learning_rate=0.0001  # ลองลด

# ถ้าดีขึ้น ค่อยปรับตัวอื่น
n_steps=4096          # ลองเพิ่ม
```

### **3. สังเกตผลลัพธ์**
- **Win Rate เพิ่มขึ้น** = ปรับถูกทาง
- **Total Return เพิ่มขึ้น** = ปรับถูกทาง
- **ผลลัพธ์ผันผวน** = ลด learning_rate
- **เรียนรู้ช้า** = เพิ่ม learning_rate

### **4. บันทึกผลลัพธ์**
```python
# เก็บ log การทดลอง
experiment_1: lr=0.0003, win_rate=60%
experiment_2: lr=0.0001, win_rate=65%  # ดีขึ้น
experiment_3: lr=0.0001, n_steps=4096, win_rate=70%  # ดีขึ้นอีก
```

## 🚨 ข้อผิดพลาดที่พบบ่อย

### **1. Learning Rate สูงเกินไป**
**อาการ**: ผลลัพธ์ผันผวนมาก
**แก้ไข**: ลด learning_rate ลงครึ่งหนึ่ง

### **2. Batch Size ใหญ่เกินไป**
**อาการ**: RAM หมด, โปรแกรมค้าง
**แก้ไข**: ลด batch_size ลงครึ่งหนึ่ง

### **3. N_Steps น้อยเกินไป**
**อาการ**: เรียนรู้ไม่เสถียร
**แก้ไข**: เพิ่ม n_steps เป็น 2-4 เท่า

### **4. Gamma สูงเกินไป**
**อาการ**: AI ไม่ตัดสินใจ (รอเรื่อยๆ)
**แก้ไข**: ลด gamma เป็น 0.9-0.95

## 📈 การวัดผลลัพธ์

### **ตัวชี้วัดสำคัญ**

| ตัวชี้วัด | ดีมาก | ดี | ปานกลาง | ต้องปรับ |
|----------|-------|----|---------|---------| 
| Win Rate | >70% | 60-70% | 50-60% | <50% |
| Total Return | >30% | 15-30% | 5-15% | <5% |
| Sharpe Ratio | >2.0 | 1.5-2.0 | 1.0-1.5 | <1.0 |
| Max Drawdown | <10% | 10-15% | 15-25% | >25% |

### **การปรับแต่งตามผลลัพธ์**

**Win Rate ต่ำ**:
- ลด learning_rate
- เพิ่ม n_epochs
- เพิ่ม lookback_window

**Total Return ต่ำ**:
- ปรับ reward function
- เพิ่ม entropy coefficient
- ลด transaction cost

**ผลลัพธ์ผันผวน**:
- ลด learning_rate
- ลด clip_range
- เพิ่ม n_steps
