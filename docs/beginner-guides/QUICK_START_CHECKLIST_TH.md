## 🎯 การปรับแต่งเร็ว

### เปลี่ยนหุ้น:
```python
# หุ้นเทค
ticker_list = ["TSLA", "NVDA", "AMD"]

# หุ้นธนาคาร
ticker_list = ["JPM", "BAC", "WFC"]

# หุ้นยอดนิยม
ticker_list = ["AMZN", "META", "NFLX"]
```

### เปลี่ยนเวลาฝึก:
```python
total_timesteps = 50000  # ฝึกมากขึ้น (ค่าเริ่มต้น: 10000)
```

### เปลี่ยนอัลกอริทึม AI:
```python
model = agent.get_model("sac")  # ประสิทธิภาพดีกว่า
model = agent.get_model("a2c")  # ฝึกเร็วกว่า
model = agent.get_model("ppo")  # ค่าเริ่มต้น, สมดุล
```

## 📊 เข้าใจผลลัพธ์

### ผลลัพธ์ดี:
- ✅ ผลตอบแทนรวม: 8-15% ต่อปี
- ✅ ตัวเลขบวก
- ✅ อัตราส่วนชาร์ป > 1.0

### ต้องปรับปรุง:
- ❌ ผลตอบแทนลบ
- ❌ การลดลงสูงมาก (>30%)
- ❌ อัตราชนะต่ำ (<40%)
