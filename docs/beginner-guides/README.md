- **เนื้อหา**: คู่มือเริ่มต้นฉบับสมบูรณ์ ตั้งแต่การติดตั้งจนถึงการเทรนโมเดลแรก

- **เนื้อหา**: คู่มือเริ่มต้นฉบับสมบูรณ์ ฉบับภาษาไทย
